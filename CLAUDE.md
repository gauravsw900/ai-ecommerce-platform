# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project
NeuroCommerce — a React 19 + Vite frontend demo for an AI-driven e-commerce & analytics platform (Tailwind CSS, lucide-react icons).

## Commands
- `npm install` — install dependencies
- `npm run dev` — start the Vite dev server
- `npm run build` — production build
- `npm run lint` — run ESLint

## Layout
- `src/main.jsx` — entry point
- `src/App.jsx` — main application component
- `src/index.css`, `src/App.css` — styles (Tailwind)

## Conventions
- Run `npm run lint` before committing.
- Keep components functional and use React hooks.
